# Engineering Portal – Technical Exercise

This project is a small React application used during the technical interview.

The exercise will involve making a series of changes to the application during the interview. Requirements will be provided one at a time by the interviewer.

You are encouraged to talk through your approach as you work. We are interested in understanding your reasoning and how you approach an unfamiliar codebase, not just whether you reach a finished solution.

## Getting Started

The project is configured to run using Vite.

Install the dependencies if required:

npm install

Start the development server:

npm run dev

The application should then be available in the StackBlitz preview.

## Project Structure

The main application code can be found under `src/`.

src/
├── data/
│   └── users.js
├── pages/
│   ├── Dashboard.jsx
│   └── Users.jsx
├── store/
│   └── userStore.js
├── App.jsx
├── App.css
├── index.css
└── main.jsx

### `data/`

Contains the sample data used by the application.

### `pages/`

Contains the main page-level React components.

### `store/`

Contains application state-related code.

### `App.jsx`

Contains the top-level application structure.

### `App.css`

Contains the majority of the application-specific styling.

### `index.css`

Contains global styles.

### `main.jsx`

The entry point for the React application.

## Technologies

The project uses:

- React
- JavaScript
- Vite
- React Router

- CSS

No additional libraries should be required for the exercise unless discussed with the interviewer.

## During the Exercise

You can modify any of the application code unless the interviewer specifies otherwise.

You may:

- Run the application at any time
- Use the browser developer tools
- Inspect the console
- Refer to existing code in the project
- Ask questions if a requirement is unclear

Please talk through your thinking as you work. If you are unsure about something, explain how you would investigate or approach it.

There is no expectation that every possible change will be completed within the interview time.
